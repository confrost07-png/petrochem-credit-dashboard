# 정유·석유화학 여신 계기판 - 기능 정리

통합앱 설계 v2를 적용한 현재 구현입니다. 실행: `app/app.py`, 화면: `app/candidates/app_minji.py`, 현재 PC 주소: http://localhost:8531/

## 현재 상태 (2026-10-07)

기업 목록 **45개**, 업종 확인 대기 후보 **19개**를 표시할 수 있습니다. 기본 화면은 API 자료가 있는 **32개 기업**, **공시 원문 · 연간** 경로는 원문을 보완한 **15개 기업**을 표시합니다. 2026H1 API 자료는 기본 목록 29개 기업에 있습니다. 후보 포함 통합 CSV는 **64개 기업·313행**, 분기 지표 **288행**, API 원본 **317건**과 원문 ZIP **43건**입니다.

**국내 전체 기업 전수 확인은 미완료**입니다. 기업개황 **2,567개**가 추가 확인 대상입니다. API가 미제공인 13개 기업의 원문 연간 수치를 추출·검산하여 반영했습니다. 차입금이나 이자 계정 부족은 핵심 수치 제공과 별도로 관리 판정을 보류합니다. 동서석유화학의 3월 결산은 `2026FY03`처럼 표시하며 12월 결산과 섞지 않습니다. [공시 원문 기능·계산 기준](AUDIT_DATA_GUIDE.md)을 확인하세요.

## 공통 화면

- 사이드바: 업종, 심사 대상 기업, 비교 기업, 분석 연도 선택.
- 분석 기간: 2021-2025 연간 / 2026H1 상반기. H1 ROA·ROE는 연환산.
- 비교 기업 0개여도 대상 기업 1개로 실행.
- 참고선: 이자보상배율 1배 / 차입금 의존도 기본 30%, 25-35% 변경 가능.
- 결론형 제목에 대상·기간·관리 단계 표시, 사용 순서 펼침 안내.
- 기업 목록 수와 실제 데이터 기업 수, 원본 수, 제공 기간 구분.
- **선택 기업 데이터 업데이트:** 해당 기업을 DART에서 수집하고 캐시를 재정제. 연결 장애·사용 제한이면 중단.
- 일부 요청에 실패해도 성공한 원본은 즉시 정제에 반영. 신규/누적 수집 건수와 중단 이유 표시.
- **DART 연결·인증 점검:** 키 인식과 실제 API status 확인. 키 값이나 인증 포함 URL은 저장하지 않음.
- 대상 기업에 최신 반기 자료가 없으면 실제 제공된 최신 연도를 기본 선택.
- 상장 구분 Y/K/N/E와 재무 데이터 제공 상태를 별도로 표시.
- 후보 표시 체크박스: 이름으로 찾은 공시 후보를 별도 노출. 업종이 확정된 기업으로 해석하지 않음.

## 탭 1. 은행 판단

### 계기판과 관리 단계

기업별 이자보상배율†, 차입금 의존도, 관리 단계(참고), 플래그 표시.

| 이자보상배율† | 차입금 의존도 | 관리 단계 | 은행 대응 |
|---|---|---|---|
| 1배 이상 | 참고선 미만 | 정상 관리 | 정기 점검 및 업종 한도 점검 검토 |
| 1배 이상 | 참고선 이상 | 관찰 (빚 부담) | 차입금 증감·단기차입 비중 점검 검토 |
| 1배 미만 | 참고선 미만 | 관리 강화 (이익 부족) | 연장·금리 조건 및 일회성 여부 확인 검토 |
| 1배 미만 | 참고선 이상 | 집중 관리 | 담보·보증 보강 및 사업재편 조건부 지원 검토 |
| 결측·자본 0 이하·불완전 차입금 매핑 | - | 판정 보류 | 누락 계정·차입금 구성·자본 상태 확인 검토 |

† 이자비용이 없으면 금융원가를 사용하며 `icr_basis`로 구분합니다. 실제 이자보상배율과 다를 수 있습니다. 관리 단계는 CSV에 저장된 소수 둘째 자리 지표로 판정합니다. 실제 은행 심사 기준·대출 가부가 아닙니다.

### 여신 관리 지도

- 가로축 이자보상배율† / 세로축 차입금 의존도. 두 참고선과 네 칸 배경·이름.
- 점 크기는 자산, 채움은 흑자 파랑·적자 빨강·0 회색, 기업은 궤적·테두리 색과 이름으로 구분.
- 선택 기간까지 ▶ 재생·멈춤·기간 슬라이더.
- 2026H1은 **다이아몬드와 점선 궤적**으로 구분. 설계서의 점선 점 테두리 대신 사용한 표기.
- 가로축 기본 -5~15배. 밖의 값은 가장자리 화살표와 실제 배율로 표시.
- 결측 좌표는 표시하지 않고 자료 부족 기업을 안내.

### 헤드룸·스트레스

모두 **시나리오 값, 원본 아님(metrics.csv 값으로 계산)**을 표시합니다.

| 기능 | 계산·예외 |
|---|---|
| 헤드룸 | `icr > 1`이면 `(1 - 1/icr) × 100`. 분모 고정 시 이익이 그만큼 감소하면 **1배에 도달** |
| 기준선 이하 | 이미 기준선 아래 / 도달·감소 여력 없음 |
| 스트레스 | 이익 감소 0-50%, 분모 증가 0-30%. `icr × (1-감소율)/(1+증가율)` |
| 과거 충격 | 2021→2022 실제 영업이익 변화율을 현재 양수 이익에 적용. 이 모드에서 슬라이더 미적용 |
| 기존 적자·이익 0 | 감소율을 곱해 손실이 좋아 보이지 않도록 현재 위치 유지 |
| 과거 자료 부족 | 2021 이익이 양수가 아니거나 두 연도 값이 없으면 과거 충격 적용 불가 |

지도 위치·관리 단계·대응 변화 표시. **차입금 의존도는 고정**되어 추가 차입 자체를 모의하지 않습니다.

### 플래그·심사 메모·사례

- **영구채:** 선택 기간 내 출처가 확인된 영구채 이벤트가 있을 때만. 현재 해당 검증 이벤트는 미등록.
- **원료 조달:** 2026H1 업종 공통 점검 항목. 개별 기업의 피해를 확정하지 않음.
- **흑자 전환:** 전년 **동일 기간** 영업적자 → 양수 이익. H1과 연간을 섞지 않음.
- **한계기업 참고조건:** 연간 배율이 3년 이상 연속 1배 미만. H1을 추가 연도로 세지 않으며 결측 연도는 연속성이 끊김. 공식·법적 분류 아님.
- Q1 수익성 / Q2 이자 부담·분모 / Q3 재무 부담 세 줄, Q4 관리 단계·대응, 출처 있는 이벤트.
- 실제 롯데케미칼 사례의 EBITDA/이자비용 **5배 약정**과 지도 **1배 참고선**을 구분.

## 탭 3. 충격 분기

2025Q1/2026Q1, 2025Q2/2026Q2 매출과 이익률을 비교합니다. 2025 연말 → 2026년 3월 말 → 6월 말 부채비율·차입금 의존도를 표시합니다.

Q2는 반기보고서 3개월 표시액을 사용합니다. H1-Q1과 다르면 경고합니다. 현재 기존 3사의 대조 **30건 중 차이 3건**입니다. 계절성·재고평가·환율 등을 고려하며 외부 충격을 변화의 원인으로 단정하지 않습니다.

## 오른쪽 하단 챗봇

- 고정 버튼 → 팝오버 질문창.
- `OPENAI_API_KEY`는 환경변수(Colab 보안 비밀) → `.streamlit/secrets.toml` → 프로젝트 루트 `.env` 순서로 찾음. 키가 없으면 **CSV 바로 답변 모드**(질문 버튼, 기업·기간·지표 질문, "2025 부채비율 가장 낮은 기업" 같은 3사 순위 질문)로 동작하며 앱 정상 실행.
- 네 질문 버튼은 선택 기업·기간의 **metrics.csv 원문 값**으로 직접 답변.
- 기업·기간·지표가 하나씩 명시된 자유 질문도 해당 행에서 직접 답변.
- 나머지는 OpenAI Responses API. CSV 외 숫자를 말하지 않게 지시하고 허용 숫자와 대조하여 미지원 숫자가 있으면 차단.
- 분기 CSV·뉴스·시나리오 숫자는 챗봇 수치 근거에 포함하지 않음.
- 투자 추천·매수·매도·주가 예측 거절, **투자 권유 아님** 표시.
- 한계: 숫자 허용 검사는 기업·기간 연결의 의미까지 완전히 검증하지 못함. 자유 답변은 원표와 함께 확인.
- 실제 키·인증 헤더는 화면·로그·ZIP에 포함하지 않음.

## 검증과 시연

판정 경계·결측·자본 이상·스트레스 손실 전환·기존 적자·헤드룸·연속 연도·축 밖 표시 검증 **8개 통과**. 기존 3사 × 6개 기간의 **KPI 108개를 metrics.csv와 대조해 일치**를 확인했습니다. 기본 실행, 자료 없는 기업, 비교 기업 0개, 과거 충격 모드를 검증했습니다. 키 없는 앱 실행과 안내만 표시도 확인했습니다. 실제 브라우저에서 계기판·네 탭·지도 재생·챗봇 위치를 확인했습니다.

시연: 롯데케미칼·2026H1 → 계기판 → 지도 ▶ 재생 → 대한유화의 ‘2022년 같은 충격’ → 근거 지표 → 충격 분기 → 데이터 기준·다운로드 → 질문 도우미. 추가 기업은 데이터 제공 상태를 반드시 함께 설명합니다.

추가 검증: 수집·부분 성공·별도 기준·차입금 중복과 합계 검산 8개 통과. 기본 목록 45개 화면을 실행하고, 데이터가 있는 32개 기업의 최신 기간 KPI 192개가 metrics.csv와 일치함을 확인했습니다. 기존 3사 수치는 변경되지 않았습니다. 원본의 `_collection.fs_div`로 연결·별도를 추적합니다. 단기/장기 구분이 명확한 BS 계정명만 추가 허용하고, 유동차입금 분리 예외는 유동부채 총계 대조로 검증합니다. 불명확한 금융부채·사채 액면금액이나 누락 차입금을 추정으로 채우지 않습니다.

PPT는 보류입니다. 기존 PDF·PNG는 이전 3사 분석 버전입니다.
