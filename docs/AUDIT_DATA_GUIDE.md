# 공시 원문 데이터 보완

## 사이트 이용 순서

1. 기본 **재무제표 API** 화면에서 기업·분석 연도를 선택합니다. 자료가 확인된 기업만 기본 목록에 표시합니다.
2. 금호피앤비화학·동서석유화학·롯데엠시시·롯데이네오스화학 등은 사이드바 **공시 원문 · 연간**으로 전환합니다.
3. 회사와 제공 기간을 선택합니다. `2025`는 2025년 12월 결산 연간, `2026FY03`은 2026년 3월 결산 연간입니다. 반기 자료가 아닙니다.
4. 은행 판단 → 근거 지표 → 데이터 기준 순서로 수치, 관리 판정의 누락 계정, DART 원문 링크와 추출 행을 확인합니다.
5. 분기 시연은 **재무제표 API** 경로의 충격 분기 탭을 사용합니다. 원문 연간 값을 분기로 바꾸지 않습니다.

## 이번에 반영한 범위

- 기존 API 자료 51개 기업(업종 확인 대기 후보 포함)에 공시 원문 13개 기업을 보완했습니다.
- 통합 `metrics.csv`: 64개 기업, 313개 기업·기간 행. 기본 확정 목록 45개 기업은 모두 일부 기간의 핵심 재무 수치가 있습니다.
- 공시 원문: 43건 ZIP, API 미제공 기간 보완 자료 16개 기업·44행. 수양켐텍은 사업보고서에 첨부된 재무제표 원문을 이용했습니다.
- DL케미칼은 2025년 연결감사보고서, SK엔무브는 2025H1 연결 반기보고서를 추가했습니다. 반기 손익은 3개월 열을 제외하고 누적 열을 사용합니다. 이엠네트웍스는 공시목록 조회(2023-01-01~2026-10-07)에서 2022년 사업보고서 이후 재무 보고서가 확인되지 않아 기존 2022년 수치를 표시합니다.
- 비교 기간 자료가 없는 기업은 최신 제공 기간의 핵심 수치를 별도 카드로 보여줍니다. 현재 기간의 비교지도·순위에는 넣지 않습니다. 대상 기업을 선택하면 최신 제공 기간으로 자동 이동합니다.
- HD현대오일뱅크 2026H1은 원문 연결 주석 17번의 단기차입금·유동성장기차입금·유동성사채·장기차입금·사채를 합산했습니다. 주석 소계 각각이 API 단기·장기 금융부채 장부가와 정확하게 일치할 때만 반영합니다. 리스부채·파생금융부채는 제외합니다. `verified_borrowings.json`은 확인한 공시·표·행 구성, `verified_note_mapping.csv`는 검증한 원문 금액입니다. 이자보상배율 7.47배는 유지되며 차입금 의존도 35.37%를 보완했습니다.
- 국내 업종 전체의 발굴 작업은 완료되지 않았습니다. 확인 대기 기업은 기존 기업개황 수집 현황을 확인합니다.

## 데이터 경로와 재현

```text
data/raw/audit/*_list.json     DART 공시 목록 응답
data/raw/audit/*.zip           document.xml API가 반환한 원문 ZIP 그대로 보존
data/processed/audit_report_index.csv       기업·공시·보고서 경로
data/processed/audit_account_mapping.csv    XML 파일·표 번호·행 번호·원문 숫자·단위
data/processed/audit_extraction_status.csv  공시별 추출·검산 결과
data/processed/audit_metrics.csv            원문에서 계산한 연간 지표
data/processed/metrics.csv                  API 지표와 원문 지표 통합, 챗봇의 유일한 수치 근거
data/processed/data_quality.csv             기업·기간별 관리 판정 가능 여부
```

프로젝트 폴더에서 설치한 Python으로 실행합니다.

```powershell
python source/collect_audit.py
python source/rebuild.py
python source/validate_data.py
python -m unittest discover -s source -p test_audit_metrics.py
streamlit run app/app.py --server.port 8531
```

원문 캐시가 있으면 재정제에는 API 키가 필요 없습니다. 신규 수집에는 비공개 `.env`의 DART_API_KEY가 필요합니다. 선택 기업 갱신 버튼은 최신 2026H1 API 원본이 없을 때 기존 연간 API 자료가 있더라도 반기·감사·사업보고서 원문 목록을 다시 조회합니다.

## 계산·표시 제한

- 본표에서 당기·전기 열을 확인하고 매출·영업손익·순손익·자산·부채·자본을 추출합니다. 괄호는 음수, 명시된 `-`는 해당 셀의 0으로 읽습니다. 누락 계정은 0으로 채우지 않습니다.
- 원·천원·백만원을 원화로 변환합니다. 자산=부채+자본 오차는 원문 표시 단위 한 단위 이내인지 확인합니다.
- 평균자산을 사용해 ROA를 계산하고, 별도 순이익/평균자본으로 ROE를 계산합니다. 연결 지배주주 계정 미확인 ROE는 비워 둡니다.
- 이자비용이 명확하면 이를 사용합니다. 없으면 본표에 명시된 금융비용·금융원가를 대리지표 분모로 사용하고 `icr_basis=금융원가`를 표시합니다.
- 명확한 본표 차입금·사채만 합산합니다. 포괄 금융부채나 매핑되지 않은 차입 계정이 있으면 차입금 의존도와 관리 판정은 보류합니다. 따라서 핵심 재무 수치 제공과 관리 판정 가능은 별개입니다.
- 추출은 자동 검산이며 모든 주석에 대한 사람의 회계 검토를 뜻하지 않습니다. 정정 공시, 차입금 장부가, 금융부채 구성은 추가 검토 대상입니다.
- 챗봇은 통합 metrics.csv만 사용합니다. 결산월과 연결/별도 기준을 구분하고, 표에 없는 수치를 말하지 않도록 제한했습니다. 투자 권유 아님.
